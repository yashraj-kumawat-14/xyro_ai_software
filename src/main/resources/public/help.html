Quick Troubleshooting

Try these checks when something isn't working.

01 XYRO is not responding +
  • Check that the robot or server is powered on.
  • Check the microphone connection and permissions if you are using voice input.
  • Speak clearly and reduce background noise.
  • For the current web interface, check the server status at the bottom of the home page.
02 Chat is not generating a response +
  • Confirm that the Java server is running.
  • Check the server status on the XYRO home page.
  • Verify that the local language model is available and loaded correctly.
  • Check the Java terminal for error messages.
  • Wait for the current response to finish before sending another message.
03 Server unavailable +
  • Make sure the XYRO Java application is running.
  • Open the home page through the Java server, rather than opening the HTML file directly.
  • Check that the server is listening on 127.0.0.1:8080.
  • Review terminal output for startup or native library errors.
04 Face recognition is not working +
  • Check the camera connection and permissions.
  • Ensure the face is clearly visible and well lit.
  • Keep the face within the camera's field of view.
  • Confirm that the face recognition service is running.

Face recognition must be implemented and connected to the current interface before its buttons can work.

05 Voice input or speech output is not working +
  • Check microphone permissions and audio connections.
  • Verify that the selected speech recognition engine is installed and running.
  • Check speaker volume and the selected text-to-speech engine.
  • Test text chat first to determine whether the problem is with the AI backend or voice system.
